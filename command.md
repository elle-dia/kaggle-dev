# Kaggle API コマンド

## 開催中のコンペ

```bash
kaggle competitions list
```

## 提供されているファイルのダウンロード

```bash
kaggle competitions download -c コンペ名
```

## コンペへのファイルアップロード

```bash
kaggle competitions submit -c コンペ名 -f ファイル名 -m "コメント"
```

## データセットのダウンロード

```bash
kaggle datasets download -d データセット名
```

## データセットの検索

```bash
kaggle datasets list
```

```bash
kaggle datasets list -s キーワード
```
